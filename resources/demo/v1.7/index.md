# ColaMD v1.7 演示

欢迎！本目录就是 v1.7 的**可玩 changelog**。左侧面板列出了同目录的所有 Markdown 文件——这正是 v1.7 的新功能：**同目录文件列表**。

## 新功能一览

| 文件 | 演示什么 | 版本 |
| --- | --- | --- |
| [tasks.md](tasks.md) | 可勾选的待办列表（点击 / ⌘+Enter） | v1.6.1 |
| [format.md](format.md) | ==高亮==、表格、公式（⌘⇧E 插入，KaTeX 渲染） | v1.6.1 / v1.7 |
| [agent-sim.md](agent-sim.md) | Agent 实时同步（核心卖点） | v1.1+ |

## 玩一下

1. **切换文件** — 点击左侧面板里的文件名，内容就地切换，当前文件高亮
2. **开关面板** — 标题栏右侧的竖线按钮，或 **⌘⇧B**
3. **勾选待办** — 打开 tasks.md，点击 checkbox 或按 ⌘+Enter
4. **插入公式** — 打开 format.md，按 **⌘⇧E**
5. **搜索** — **⌘F**

## 模拟 Agent

打开终端，对当前目录里的文件做改动，窗口会实时刷新：

```bash
echo '- [ ] 这是 Agent 刚写入的任务' >> tasks.md
echo '# 全新文件' > new.md
```

第二行会**实时**出现在左侧面板里。这是演示副本，改坏了随时可以从仓库恢复。
